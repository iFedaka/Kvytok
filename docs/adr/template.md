# Short title, stated as the decision

## Context and Problem Statement

What forces the decision, in a few sentences, ending in the question being answered.

## Decision Drivers

* A constraint or goal the options are judged against. Say what it costs to miss it.

## Considered Options

* Option A
* Option B

## Decision Outcome

Chosen option: "Option A", because the reason that decided it, not a list of its merits.

How the chosen option works, where a reader needs that to judge it. Use subsections
(`### Name`) for mechanisms, numbers and limits.

### Consequences

* Good, because …
* Bad, because … (the costs accepted; leave none out)

### Confirmation

How to tell the decision holds: a startup check, a test (by name), a measurement or a runbook
query, each linked. Say what is measured and what is only estimated.

## Why not the alternatives

### Option B

* Good, because … (what it genuinely does better)
* Bad, because … (why it lost)

## When this would be the wrong call

Optional. The conditions under which a rejected option becomes the right one, so the decision
can be reopened on evidence and not on mood.

## More Information

Optional. Follow-ups, the first step if a limit is reached, related ADRs and docs.
